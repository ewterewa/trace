# TRACE — Design Guidelines

## Visual direction
Premium editorial intelligence software: restrained, precise and functional. Avoid generic AI dashboard styling, excessive cards, heavy gradients and ornamental glow.

## Palette
- Background #080808
- Surface #101112
- Elevated surface #171819
- Primary text #EEEAE8
- Muted text #858184
- Powder-pink accent #E9BDC8
- Secondary accent #BD8D9B
- Borders #242426

## Typography
Manrope for interface typography; DM Mono for IDs, timestamps, labels and technical metadata. Use clear hierarchy and generous negative space.

## Interaction
Motion should communicate state or spatial relationships. Keep controls usable on touch screens. Graphs and globe should have a textual alternative for key data. Never rely on color alone for status.

## Globe integrity
The MVP globe is illustrative. Production map markers may only appear when a source supports the location, with uncertainty and source references visible.
